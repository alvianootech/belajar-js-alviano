# Tugas 04 — Konversi Suhu

## Tujuan
Melatih pembuatan fungsi dengan parameter dan nilai kembalian (`return`).

## Instruksi
1. Buat fungsi `celsiusToFahrenheit(celsius)` yang **me-return** hasil konversi.
   Rumus: `F = C x 9/5 + 32`
2. Buat fungsi `celsiusToReamur(celsius)` yang juga me-return hasil.
   Rumus: `R = C x 4/5`
3. Panggil kedua fungsi dengan beberapa suhu berbeda (contoh: 0, 25, 100) dan tampilkan hasilnya.

## Contoh Output
```
25°C = 77°F
25°C = 20°R
100°C = 212°F
100°C = 80°R
```
